# Quick Task 260801-002: OfflineSyncBootstrap Lifecycle Race

**Gathered:** 2026-08-01
**Status:** Implemented and verified

## Scope

Guard the OfflineSyncBootstrap State object after asynchronous auth/cache work, preserve logged-out handling and sync error handling, and prevent duplicate or overlapping sync from rapid rebuilds.

## Decisions

- Keep Appwrite and cache providers resolved before the first await.
- Add mounted guards after `getCurrentUser()` and `OfflineCache.init()`.
- Set the in-flight flag before awaiting auth, reset it in `finally`, and keep the existing narrow sync-error catch.
- Use focused source-contract tests because the production services are singleton-backed and the repository already uses this lifecycle-test pattern.
